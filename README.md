## SimpleVideoStreamingService

파이썬 가상환경 생성

```bash
python3 -m venv venv
```

&nbsp;

가상환경 실행

```bash
source venv/bin/activate
```

&nbsp;

가상환경에 모듈 설치

```bash
pip install opencv-python numpy
```

서버 실행

```bash
docker compose up --build
```

&nbsp;

클라이언트 실행 코드

```bash
python client.py
```
